# Online Cloth Rental System

A comprehensive PHP-based online cloth rental system that allows users to rent clothing items with an admin panel for management.

## Features

### User Features
- User registration and login
- Browse clothing categories
- View product details
- Add items to cart and wishlist
- Place rental orders
- Track order status
- Manage profile and addresses
- Order history

### Admin Features
- Dashboard with analytics
- Manage categories and subcategories
- Add/edit rental clothing items
- Order management (new, packed, dispatched, delivered, etc.)
- User management
- Review management
- Sales reports

## Technology Stack

- **Backend**: PHP
- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Database**: MySQL
- **Libraries**: jQuery, Owl Carousel, Easy Responsive Tabs

## Installation

1. Clone the repository
2. Set up a web server (Apache/Nginx) with PHP support
3. Create a MySQL database
4. Import the database schema
5. Configure database connection in `ocrs/includes/config.php`
6. Access the application through your web server
